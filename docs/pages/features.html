Feature Overview

WRLA adds a Laravel admin panel for managing Eloquent records, users, and site settings. It also includes tools for operating the application. Start here to see what you can use before installing.

Manage application data

FeatureWhat you can do
Manageable ModelsGive an Eloquent model its own browse, create, and edit screens. Add actions for deleting, duplicating, and restoring records. Open forms in a modal or on their own page.
Browse and filterDefine search, select, and soft-delete filters. Remember filters, scope the query, choose the default sort, select multiple records, or enable manual reordering.
Columns and actionsShow text, dates, icons, checks, images, and links. Add actions to a row or the browse toolbar. Import CSV data with column mapping or export browse results as CSV.
Form fieldsUse text and rich-text editors, choices and search, tags, dates, prices, file and image uploads, image cropping, and repeatable or JSON-backed fields. Add Laravel validation rules.
Site ConfigurationInstall an optional settings table and admin screen. Let admins edit values your application reads at runtime.

Build and secure the panel

FeatureWhat you can do
AuthenticationUse WRLA's sign-in and password reset screens or keep your application's login. Configure Turnstile, authenticator-app MFA, and rate limits.
Users and accessManage accounts and profile details. Assign admin or master privileges. The generated User model includes optional impersonation, disabled by default. Set rules per model or action with Model Permissions.
Dashboard, pages, and navigationAdd Livewire pages, change the dashboard, and decide which links appear in the sidebar.
Appearance and settingsChange the admin URL, branding, colors, themes, and CSS. Keep callback-based rules in runtime settings so the Laravel config can be cached.
Notifications and emailSend in-panel notifications to users or groups. Add links or buttons, or send email from an editable template with variable substitution.

Operate the application

Access to these tools can be restricted separately from model access. See Admin Tools for setup.

ToolWhat you can do
File ManagerBrowse configured Laravel disks. Preview, upload, replace, or delete files and manage folders.
LogsUse WRLA's log viewer or Opcodes Log Viewer. Configure separate WRLA log channels for errors, information, and events.
Database BrowserInspect and filter raw records, or allow create, edit, and delete. Restrict connections and tables or use read-only mode.
Database SchemaExplore a Truss diagram of your schema. Embed it in WRLA or open it as a separate page.
Scheduler & JobsInspect Laravel's scheduled tasks and run tasks manually when allowed. View supported queue stores, retry failed jobs, or remove jobs.
Developer ToolsExpose a configured list of maintenance commands to authorized admins.
Artisan commandsSet up or update WRLA, generate model and notification classes, manage users, and serve the documentation locally.

Try it with an existing model

After installation, scaffold a management screen for an existing Product model:

php artisan wrla:manageable-model Product
