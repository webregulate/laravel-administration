Form Fields

Return fields from getManageableFields(). WRLA uses the same list for create and edit, whether the form opens on a page or in a modal.

Build a product form

Pass the Manageable Model instance and Eloquent attribute to each field. Add Laravel validation rules with validation().

use WebRegulate\LaravelAdministration\Classes\ManageableFields\Select;
use WebRegulate\LaravelAdministration\Classes\ManageableFields\Text;
use WebRegulate\LaravelAdministration\Classes\ManageableFields\TextArea;

public function getManageableFields(): array
{
    return [
        Text::make($this, 'name')->validation('required|string|max:120'),
        Select::make($this, 'status', [
            'draft' => 'Draft',
            'published' => 'Published',
        ])->validation('required|in:draft,published'),
        TextArea::make($this, 'description'),
    ];
}

Field reference

Import field classes from WebRegulate\LaravelAdministration\Classes\ManageableFields. The examples go in the array returned by your model's getManageableFields().

FieldUse it forExample
TextSingle-line text or an HTML input type such as email.Text::make($this, 'email')->setAttribute('type', 'email')
TextAreaMultiline plain text.TextArea::make($this, 'description')
WysiwygRich text. Choose the editor in Configuration.Wysiwyg::make($this, 'body')
PasswordA write-only password and confirmation. A blank edit leaves the existing hash unchanged.Password::make($this, 'password')
SelectA dropdown from a value-to-label map.Select::make($this, 'status', ['draft' => 'Draft'])
SearchSelectSearch Eloquent records and store the selected model's key.SearchSelect::make($this, 'category_id')->searchQuery(Category::class, 'name')
SearchableValueA searchable list of values. Supply a map or load choices with callbacks.SearchableValue::make($this, 'region')->setItems(['uk' => 'United Kingdom'])
TagsA list of tags with optional suggestions and a limit.Tags::make($this, 'tags')->commonTags(['featured'])->maxTags(5)
DateDate, time, or local date/time. Pass ['defaultNow' => false] as the fourth argument to start without a default.Date::make($this, 'starts_at', Date::TYPE_DATETIME)
MonetaryValueDisplay a decimal amount while storing an integer in minor units. With multiplier 100, £12.50 stores as 1250.MonetaryValue::make($this, 'price_pence')
FileUpload one file to a Laravel storage disk. The default disk is public.File::make($this, 'manual', 'manuals')->validation('mimes:pdf')
ImageUpload an image with a preview and optional server-side sizing.Image::make($this, 'photo', 'products')->coverFitAspect(800, '4/3')
ImageCroppableLet the admin crop an uploaded image.ImageCroppable::make($this, 'avatar', 'avatars')->aspect('1/1')
MultiImageStore several images in one field. Set the disk, directory, count, and upload rules.MultiImage::make($this, 'gallery', path: 'products/gallery', maxImages: 4)
JsonEdit raw JSON and optionally validate its keys.Json::make($this, 'metadata')
JsonUIEdit JSON values with form controls instead of raw JSON text.JsonUI::make($this, 'settings')->mergeDefaultKeyValues(['featured' => false])

Labels, defaults, and validation

Text::make($this, 'sku')
    ->setLabel('Stock code')
    ->setAttribute('placeholder', 'ABC-123')
    ->validation('required|string|max:32')
    ->inlineValidation(fn ($value) => $value !== 'reserved'
        ? true
        : 'Choose another stock code.'),
  • validation() appends Laravel rules. Pass overwrite: true to replace a field's defaults.
  • inlineValidation() takes a callback that returns true or an error message.
  • default() sets an initial value on create; it does not replace the value on edit.
  • Use showOnlyOn(PageType::CREATE) or hideFrom(PageType::EDIT) to change which forms display a field. Import PageType from WebRegulate\LaravelAdministration\Enums.

Store tags

use WebRegulate\LaravelAdministration\Classes\ManageableFields\Tags;

// Add to the getManageableFields() return array.
Tags::make($this, 'tags', ['commonTags' => ['featured', 'seasonal']]),

Use an Eloquent array cast for a JSON list, or leave a text attribute uncast for a comma-separated string. WRLA removes duplicates without changing the storage format.

Repeat a group of fields

use WebRegulate\LaravelAdministration\Classes\ManageableFields\MultiField;
use WebRegulate\LaravelAdministration\Classes\ManageableFields\MultiFieldItem;

// Add to the getManageableFields() return array.
MultiField::make($this, 'resources')
    ->setItems([
        MultiFieldItem::text('title', 'Title'),
        MultiFieldItem::url('url', 'Link'),
        MultiFieldItem::select('type', ['guide' => 'Guide', 'video' => 'Video']),
    ])
    ->addItemLabel('Add resource')
    ->maxFormGroups(5)
    ->useColumnLayout(2),

Other item builders are date(), number(), textarea(), and image(). The default row layout places each entry's fields side by side. Column layout stacks the fields within each entry.

To change where forms open or where users go after saving, see mainSetup().
