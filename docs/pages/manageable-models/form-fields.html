Form Fields

Return fields from getManageableFields(). WRLA uses the same list for create and edit, whether the form opens on a page or in a modal.

Build a product form

Pass the Manageable Model instance and Eloquent attribute to each field. Add Laravel validation rules with validation().

use WebRegulate\LaravelAdministration\Classes\ManageableFields\Select;
use WebRegulate\LaravelAdministration\Classes\ManageableFields\Text;
use WebRegulate\LaravelAdministration\Classes\ManageableFields\TextArea;

public function getManageableFields(): array
{
    return [
        Text::make($this, 'name')->validation('required|string|max:120'),
        Select::make($this, 'status', [
            'draft' => 'Draft',
            'published' => 'Published',
        ])->validation('required|in:draft,published'),
        TextArea::make($this, 'description'),
    ];
}

Pick a field type

Use caseFields
Text and formattingText, TextArea, Wysiwyg, Password
Choices and lookupsSelect, SearchSelect, SearchableValue, Tags
Dates and pricesDate, MonetaryValue
UploadsFile, Image, ImageCroppable, MultiImage
Structured or repeated dataJson, JsonUI, MultiField with MultiFieldItem
Layout and hidden valuesHeading, BladeElement, Hidden

Store tags

use WebRegulate\LaravelAdministration\Classes\ManageableFields\Tags;

// Add to the getManageableFields() return array.
Tags::make($this, 'tags', ['commonTags' => ['featured', 'seasonal']]),

Use an Eloquent array cast for a JSON list, or leave a text attribute uncast for a comma-separated string. WRLA removes duplicates without changing the storage format.

To change where forms open or where users go after saving, see mainSetup().
