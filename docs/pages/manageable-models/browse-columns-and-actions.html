Browse Columns & Row Actions

Choose what each row shows and what an admin can do with it.

getBrowseColumns()

Use the model attribute as the key. The value is a label or a column formatter.

use WebRegulate\LaravelAdministration\Classes\BrowseColumns\BrowseColumnCheck;
use WebRegulate\LaravelAdministration\Classes\BrowseColumns\BrowseColumnDate;

public function getBrowseColumns(): array
{
    return [
        'name' => 'Product',
        'active' => BrowseColumnCheck::make('Active'),
        'created_at' => BrowseColumnDate::make('Added', 'd M Y'),
    ];
}

Column formatters

Import these classes from WebRegulate\LaravelAdministration\Classes\BrowseColumns.

FormatterWhat it showsExample
BrowseColumnText. Set a character limit or pass a formatter receiving the value and Eloquent model.BrowseColumn::make('Description')->limit(60)
BrowseColumnCheckDifferent icons for true and false values.BrowseColumnCheck::make('Active')->trueIcon('fa-solid fa-check')
BrowseColumnDateA formatted date with a fallback for missing values.BrowseColumnDate::make('Added', 'd M Y')->setFallback('Unknown')
BrowseColumnIconAn icon class returned by a callback that receives the Eloquent model.BrowseColumnIcon::make('Type', fn ($model) => 'fa-solid fa-box')
BrowseColumnImageA linked thumbnail. Pass a URL or a callback that receives the value and model.BrowseColumnImage::make('Photo', fn ($value) => $value, 80)
BrowseColumnLinkA link from a callback that returns url and text, or null to render nothing. Enable HTML output for the generated link.BrowseColumnLink::make('Details', fn ($value) => ['url' => route('products.show', $value), 'text' => 'View'])->renderHtml()
BrowseColumnManageableModelA link to a related record's WRLA edit page. The browse column value becomes the link text.'category.name' => BrowseColumnManageableModel::make('Category', 'category.id', \App\WRLA\Category::class)

Use allowOrdering(false) for a column that should not be sortable. Use headerClass() or columnClass() to style just the header or cells.

Mobile layout

Below 768px, browse tables size columns to their content and wrap plain text. Use ->hideOnMobile() to hide a column's header and cells without changing desktop visibility or CSV exports. Use ->mobileWidth(40) on a BrowseColumnImage to set a mobile thumbnail width. Integers are pixels; CSS lengths such as '3rem' also work.

'name' => BrowseColumn::make('Name')->hideOnMobile(),
'avatar' => BrowseColumnImage::make('Avatar', fn ($value) => $value, 80)->mobileWidth(40),

getInstanceActions()

Return the buttons you want to show. Import these classes from WebRegulate\LaravelAdministration\Classes\InstanceActions.

ActionBehaviorPermission used by the button
InstanceActionEditOpen a record for editing.EDIT
InstanceActionDuplicateStart a new record using values from the selected record.CREATE
InstanceActionDeleteDelete the record. A record already in the trash can be deleted permanently.DELETE
InstanceActionRestoreRestore a soft-deleted record. Use only with models that support soft deletes.RESTORE
 
use WebRegulate\LaravelAdministration\Classes\InstanceActions\InstanceActionDelete;
use WebRegulate\LaravelAdministration\Classes\InstanceActions\InstanceActionEdit;
use WebRegulate\LaravelAdministration\Classes\InstanceActions\InstanceActionRestore;

public function getInstanceActions(): array
{
    return [
        InstanceActionEdit::make($this),
        // Add InstanceActionDuplicate::make($this) to offer duplication.
        InstanceActionRestore::make($this),
        InstanceActionDelete::make($this, $this->isModelSoftDeleted()),
    ];
}

The delete button warns about permanent deletion if the record is already in the trash. Turn on setMultiSelect(true) in browseSetup() to offer supported actions for multiple rows.

Add a custom row action

Pass a URL to render a link, or pass a callback to run server-side. This example uses an application route named products.show.

use WebRegulate\LaravelAdministration\Classes\InstanceAction;

// Add to the getInstanceActions() return array.
InstanceAction::make(
    $this,
    'Preview',
    'fa-solid fa-eye',
    action: route('products.show', $this->model()->getKey()),
),
  • A callback receives the row model and can return a message, an alert array, a redirect, a file response, or null.
  • Use confirm() to ask before running an action or requireCondition() to control when the action is enabled. Still authorize the operation server-side.
  • Use multiAction() to define a separate handler for selected record IDs. Enable multi-select in browseSetup() to show it.

Import and export CSV

Add these to the model's browse toolbar. Keep any existing actions you still want to show.

use WebRegulate\LaravelAdministration\Classes\BrowseActions\BrowseActionExportCSV;
use WebRegulate\LaravelAdministration\Classes\BrowseActions\BrowseActionImport;

// Inside browseSetup()
static::setBrowseActions(
    BrowseActionImport::make(static::class),
    BrowseActionExportCSV::make(static::class),
);
  • Import: Upload a CSV with headers, map them to database columns, and check the preview before importing. The single-row import writes a real record; it is not a dry run.
  • Export: Download the filtered browse results, not just the current page. The toolbar asks how many rows to export when there are more than 1,000.

Import uses database inserts, not the Manageable Model form's save flow. Do not rely on form validation or Eloquent save events to prepare CSV data. Configure upload rules, ignored columns, and chunk size under csv_imports in Configuration.
