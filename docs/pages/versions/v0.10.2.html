Fixes the Tags field when a value contains duplicates or enough tags to push the add box out of view.

Breaking Changes

  • None. Comma-separated tag columns stay comma-separated, and array/JSON tag columns stay JSON lists.

Fixes

  • Entering a tag that is already on the field shows a warning in the existing alert popouts and clears the input.
  • Tags and the add input wrap onto extra lines, so the input stays on screen when there are many tags.
  • Duplicate tags are removed when the field is displayed and again when it is saved, in the same order, so the stored value matches the pills.
