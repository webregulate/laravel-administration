Adds configurable modal create and edit forms for manageable models, while retaining the existing full-page workflow as the default.

Breaking Changes

  • None. Existing manageable models continue to use full-page upsert forms by default.

Features

  • Create, edit, and duplicate actions can now open the existing upsert form in a modal.
  • Presentation can be configured globally or overridden per manageable model.
  • Modal width and post-save behaviour are configurable without creating a custom modal component.

Model-level usage

Import UpsertOptions and call static::setUpsertOptions() from the manageable model's mainSetup() method. 

use WebRegulate\LaravelAdministration\Classes\UpsertOptions;

public final static function mainSetup(): void
{
    // ...

    static::setUpsertOptions(UpsertOptions::modal('6xl'));
}

Use UpsertOptions::default() for the globally configured mode, UpsertOptions::page() for the standard page, UpsertOptions::modal() for the configured modal width, or pass a Wire Elements Modal width key explicitly: sm, md, lg, xl, 2xl, 3xl, 4xl, 5xl, 6xl, or 7xl. 

// Keep either page or modal form open after a successful save
static::setUpsertOptions(
    UpsertOptions::modal('6xl')->returnToBrowseAfterSave(false)
);

Configuration

Add the following block to your published config/wr-laravel-administration.php. These defaults preserve the previous full-page workflow unless a model opts into modal mode. 

'upsert' => [
    // Default upsert mode: 'page' or 'modal'
    'mode' => 'page',

    'page' => [
        // Redirect to browse after save when true; otherwise keep the form open
        'return_to_browse_after_save' => false,
    ],

    'modal' => [
        // Wire Elements Modal width: sm, md, lg, xl, or 2xl through 7xl
        'size' => '6xl',

        // Close the modal and return to browse after save when true
        'return_to_browse_after_save' => true,
    ],
],

Per-model options take precedence over these values. Calling UpsertOptions::page() or UpsertOptions::modal() still reads the corresponding post-save default from this configuration.
