Improves manageable model browse actions with native page navigation from modal edit links, manual refreshing, and reusable upsert modal JavaScript helpers.

Breaking Changes

  • None.

Improvements

  • When modal upsert mode is enabled, edit actions can now be middle-clicked to open the full-page upsert form in a new tab.
  • Manageable model browse pages now include a refresh action beside the per-page selector.
  • The refresh icon and button show a clear loading state while records are refreshed.

upsertModal()->onclick()

Manageable models now provide a helper for generating the JavaScript needed to open an upsert modal from custom buttons and links. 

// Generate an onclick handler for editing record 76.
$onclick = ApplicationConfig::upsertModal(76)->onclick();

// Prevent normal navigation when using an anchor with an href fallback.
$linkOnclick = ApplicationConfig::upsertModal(76)->onclick(preventNavigation: true);
