Version History

Simplifies how custom WRLA pages are registered. Full-page Livewire components are now registered with a plain Route::get() in a renamed buildRoutes() method, replacing the old buildCustomRoutes() + WRLAHelper::registerLivewireRoute() approach.

Breaking Changes

  • WRLASettings::buildCustomRoutes() has been renamed to buildRoutes(). If you don't rename it, your custom routes will stop being registered.
  • WRLAHelper::registerLivewireRoute() has been removed. Register full-page routes with a plain Route::get('url', Component::class)->name('wrla.name').
  • Custom full-page Livewire components must now extend WRLAPageComponent instead of Livewire\Component so they render inside the WRLA admin layout.

Upgrade Guide

1. Rename buildCustomRoutes() to buildRoutes()

In app/WRLA/WRLASettings.php, rename the method: 

// Before
public static function buildCustomRoutes(): void

// After
public static function buildRoutes(): void

2. Register each page with a plain Route::get()

Replace every registerLivewireRoute() call inside buildRoutes() with a normal route pointing at the component class: 

use Illuminate\Support\Facades\Route;
use App\Livewire\WRLA\MyPage;

// Before
WRLAHelper::registerLivewireRoute(
    'my-page', 'wrla.my-page', MyPage::class, [], 'My Page'
);

// After
Route::get('my-page', MyPage::class)->name('wrla.my-page');

3. Make each page component extend WRLAPageComponent

Update your full-page Livewire components so they render inside the admin layout. Use the standard Livewire #[Title] attribute to set the page title: 

use Livewire\Attributes\Title;
use WebRegulate\LaravelAdministration\Livewire\WRLAPageComponent;

#[Title('My Page')]
class MyPage extends WRLAPageComponent
{
    public function render()
    {
        return view('livewire.wrla.my-page');
    }
}

The component's view is now a plain Livewire view (a single root <div>) — you no longer need the @extends / @section wrapper.

Features

  • New WRLAPageComponent base class renders any Livewire component as a full page in the WRLA admin layout. Set a static title with #[Title] or override getPageTitle() for a dynamic one.
  • Registering WRLA pages now uses standard Laravel routing (Route::get('url', Component::class)), so it works the same as any other Livewire full-page route.
  • The built-in wrla.dashboard route can now be overridden simply by defining your own in buildRoutes(). If you don't, the default dashboard is still registered automatically.
