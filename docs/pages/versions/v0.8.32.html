Fixes ImageCroppable fields when manageable model upsert forms are opened in a modal.

Breaking Changes

  • None.

Fixes

  • The cropping area remains hidden until a new image is selected.
  • Selecting a local image now starts the cropping process when the upsert form is displayed in a modal.
  • Cropped image upload and validation failures now display feedback instead of silently stopping the save action.
  • Modal upsert forms now smoothly scroll to the first validation error after a rejected save.
