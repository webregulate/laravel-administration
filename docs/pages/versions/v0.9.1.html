Fixes the missing UpsertOptions import in the generated User manageable model.

Fixes

  • New installations correctly resolve UpsertOptions::default().
  • Includes the restored WRLAUserData stub docblock and documentation.

Upgrade Steps

Run composer update webregulate/laravel-administration. Existing generated User manageable models that call UpsertOptions::default() need this import if it is missing: 

use WebRegulate\LaravelAdministration\Classes\UpsertOptions;

Use 0.9.1 rather than the re-tagged 0.9.0: Packagist keeps stable version references immutable, so the original 0.9.0 snapshot does not contain these fixes.
