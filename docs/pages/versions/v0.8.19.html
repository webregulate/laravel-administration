Version History

Adds the ability to switch each email template between Markdown and HTML mode directly in the backend, so you can author content in whichever format best suits the template.

Breaking Changes

  • None

Features

  • Each email template can now be switched between Markdown and HTML mode from the backend, letting you choose the authoring format on a per-template basis.
  • The chosen mode is saved with the template, so existing templates keep rendering exactly as before while new ones can opt into whichever format suits them.
