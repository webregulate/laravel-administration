Refines modal upsert forms with cleaner presentation, visible rounded corners, and protection against accidentally discarding unsaved changes.

Breaking Changes

  • None.

Improvements

  • Modal upsert forms no longer render an additional padded, bordered, and shadowed inner container.
  • Modal layouts now preserve their rounded outer corners in both light and dark themes.
  • Clicking the backdrop of a changed upsert form now asks for confirmation before discarding unsaved changes.
  • The default alert top offset is now 38px.

Configuration

Update the alert offset in published configuration to match the new default: 

'alerts' => [
    // ...
    'top_offset' => '38px',
],
