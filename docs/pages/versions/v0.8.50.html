Consolidates changes since v0.8.32, including reorderable models, Laravel 13 and Livewire 4 support, and improved modal workflows.

Breaking Changes

  • Manageable model create/edit forms now open in a modal by default. Set upsert.mode to page to retain full pages.
  • Successful saves now remain on the form by default. Set return_to_browse_after_save to true for the previous behaviour.
  • Removed or replaced MultiField images are now deleted from storage. Use unlinkOld(false) to retain them.

Changes & Improvements

  • Manageable models can now be reordered by drag and drop in a modal or dedicated page.
  • Added Laravel 13, Livewire 4, and Wire Elements Modal 3 support.
  • Modal forms gained responsive widths, loading states, click-away handling, reliable browse refreshes, and improved create/edit state.
  • Improved disabled fields, empty values, image uploads, file deletion feedback, and field layouts.
  • Improved email rendering and encoding, plus self-hosted TinyMCE and license-key support.
