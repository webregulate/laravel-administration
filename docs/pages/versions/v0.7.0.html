Version History

First tagged release. WRLA now uses standard git tags for versioning instead of tracking dev-main against an internal version list.

Breaking Changes

  • Projects should move from the dev-main constraint to a tagged constraint. Update your composer.json to "webregulate/laravel-administration": "^0.7.0" and run composer update webregulate/laravel-administration.

Features

  • Versioning is now driven by public git tags, published automatically to Packagist. The in-app version bar, the update modal and this documentation all read those tags directly.
  • Removed the internal versions.json file and its supporting git hook / workflow — there is nothing extra to maintain when releasing.
  • The update check now compares your installed tag against the latest tagged release to decide whether an update is available.

Bug Fixes
