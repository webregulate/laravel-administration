Notifications & Email

Use notifications for the admin panel and email templates for messages sent through Laravel mail.

Create an in-app notification

php artisan wrla:notification ReportReady

Edit the generated class in app/WRLA/NotificationDefinitions/, then call it from your application:

use App\WRLA\NotificationDefinitions\ReportReady;

ReportReady::make($user->id, [
    'message' => 'Your monthly report is ready.',
]);

Pass a user ID or a user_groups key from WRLASettings::runtime(). The generator can also scaffold email delivery and buttons.

Send an email template

Create a template in Email Templates with the alias report-ready. Use {{ name }} in the body where the recipient's name should appear.

use WebRegulate\LaravelAdministration\Models\EmailTemplate;

$sent = EmailTemplate::getByAlias('report-ready', [
    'name' => $user->name,
])->sendEmail($user->email);

A missing alias throws an exception. Configure the smtp mailer, or pass the name of another configured SMTP mailer with smtpKey:. Check the return value when delivery matters.
