Artisan Commands

Run these commands from the root of your Laravel application.

Setup and maintenance

CommandWhat it does
wrla:installPublish application files and assets. The wizard offers to migrate the database and create a master administrator.
wrla:site-configurationInstall the optional Site Configuration table and models.
wrla:docsServe the docs locally. Set --port to change the default port of 8888.
wrla:updateUpdate through Composer and run the application upgrade flow. Use --yes only when you intend to approve application file changes.
wrla:upgradeMigrate application files for the 0.10.1 configuration change. Use --dry-run to preview or --yes to approve.
wrla:uninstallPrompt to remove WRLA files and its Composer dependency. Review what will be removed before accepting.

Scaffolding and users

CommandWhat it does
wrla:manageable-modelGenerate a Manageable Model. Pass a model name or supply it at the prompt.
wrla:model-docblockGenerate Eloquent @property annotations from database columns. Review before writing or use --force to skip confirmation.
wrla:notificationGenerate a notification definition. Options include --email, --buttons, and --button-type=url or livewire.
wrla:create-userCreate a user. Pass master for a master administrator or --user-model to specify a user model.
wrla:edit-userFind an existing user and edit account details or WRLA privileges.

Examples

php artisan list wrla
php artisan wrla:docs --port=8890
php artisan wrla:manageable-model Product
php artisan wrla:upgrade --dry-run
