Authentication

Authentication is how users sign in. WRLA uses your application's Laravel authentication by default.

Use the built-in login

Create a user, then open /wr-admin/login. Replace wr-admin if you changed base_url.

php artisan wrla:create-user
php artisan wrla:edit-user

The second command lets you grant admin access to an existing account. Signing in alone does not grant access to WRLA.

Use your app's login instead

Set this in config/wrla.php to turn off WRLA's login and password reset routes:

'wrla_auth_routes_enabled' => false,

Keep your app's own password reset and MFA flows. After sign-in, send eligible admins to route('wrla.dashboard'). WRLA returns a 404 if they don't have admin access.

See Configuration for Turnstile, MFA, and rate limits, and Authorization for admin access rules.
